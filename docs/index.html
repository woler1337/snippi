02OCR

Достань текст откуда угодно

Открываешь PDF, видишь нужный фрагмент. Жмёшь ⌘⇧1 / Ctrl+Shift+1, выделяешь область — текст уже в буфере. Работает офлайн через Apple Vision.

  • ~80 языков, включая русский, украинский, китайский, японский
  • Никаких изображений никуда не отправляется
  • 1–2 секунды распознавания на средний абзац

03Перевод

Переведи любой текст с экрана

⌘⇧2 / Ctrl+Shift+2 → область → распознавание → перевод → буфер. Один shortcut, один select, готово.

  • Целевой язык выбираешь в настройках (English, Русский, Deutsch, и ещё 80)
  • Автоопределение языка-источника
  • Перевод через MyMemory API — никаких ключей, никакой регистрации

Приватность

Локальный по умолчанию

Не «мы не смотрим» — а «нам физически нечего смотреть». Данные не покидают компьютер.

Всё хранится на диске

Сниппеты, история буфера и настройки — обычные локальные файлы. Нет аккаунта, нет облака, нет телеметрии.

OCR работает офлайн

Распознавание — Apple Vision на Mac, Tesseract на Windows и Linux. Скриншоты никогда не покидают компьютер.

Код открыт — проверь сам

Весь код на GitHub под MIT. Служба безопасности компании может прочитать каждую строку.

Единственное исключение — функция «Скриншот → перевод»: распознанный текст (только текст, не изображение) отправляется в MyMemory API для перевода, и только когда ты явно нажал этот шорткат. Подробности — в политике конфиденциальности.

FAQ

Частые вопросы

Что отправляется в интернет?

Только распознанный текст для функции «Скриншот → перевод» — он уходит в MyMemory Translated API. Сами скриншоты никогда не покидают компьютер. OCR работает локально через Apple Vision (Mac) или Tesseract (Windows/Linux). Сниппеты, история буфера, статистика — всё локально.

Можно ли использовать на работе?

Да. Сниппеты хранятся только на твоём компьютере, никаких облаков. Открытый код позволяет службе безопасности проверить что приложение делает. Поддержка корпоративных шаблонов через экспорт/импорт JSON.

Это правда бесплатно? Где подвох?

Приложение полностью бесплатное. Подвоха нет — это side-project, который мы развиваем потому что сами им пользуемся. В будущем может появиться платный Pro-тариф с дополнительными функциями (синхронизация между устройствами, премиум-движок перевода), но текущий функционал останется бесплатным навсегда.

Чем отличается от TextExpander.com?

TextExpander — это подписка $40/год за text-expanding функции и облако сниппетов. Snippi — бесплатно, локально, и плюс OCR / переводчик / fuzzy-палитра поиска / история буфера, которых у них нет. Зато у TextExpander есть командная подписка для рабочих групп.

Что нужно разрешить на macOS?

Два разрешения в Системных настройках → Конфиденциальность и безопасность: Универсальный доступ (для перехвата клавиш сниппетов) и Запись экрана (для функций OCR / перевод). Оба настраиваются один раз, при первом запуске приложение само подскажет.

Что если иконка не появилась в menu bar?

Редкая проблема на macOS 26+ (Tahoe) — SystemUIServer иногда «зависает». Решается одним кликом: правый клик по dock-иконке Snippi → меню трея → «Сбросить menu bar». Через секунду иконка вернётся.

Можно посмотреть исходный код?

Да — github.com/woler1337/snippi. Лицензия MIT, можно форкать, изучать, контрибьютить.
