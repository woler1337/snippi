# Установка Snippi

Выберите свою операционную систему ниже. Скачивание — со страницы **[Releases](https://github.com/woler1337/snippi/releases/latest)**.

---

## 🍎 macOS

### 1. Какой DMG скачать?

- **Меню Apple → Об этом Mac → Чип**:
  - «Apple M1/M2/M3/M4» → скачать **`Snippi-X.Y.Z-arm64.dmg`**
  - «Intel» → скачать **`Snippi-X.Y.Z-x64.dmg`**

### 2. Установка

1. Откройте скачанный DMG.
2. Перетащите **Snippi** в папку **Applications**.
3. Извлеките образ (правый клик по иконке диска на рабочем столе → «Извлечь»).
4. Откройте **Launchpad** или Spotlight (`Cmd+Space`) → запустите **Snippi**.

### 3. Первый запуск — «Apple не может проверить разработчика»

Это нормально — приложение не подписано Apple Developer-сертификатом ($99/год, разработчик пока не оформлял).

Решение **одноразовое**:
1. Нажмите **Cancel** на предупреждении.
2. Откройте **Finder → Программы**.
3. Сделайте **правый клик** на **Snippi** → **Open**.
4. В появившемся диалоге снова жмите **Open**.

После этого приложение запускается двойным кликом как обычно.

> **Если macOS пишет «Snippi повреждён и не может быть открыт»** (бывает на macOS Sequoia/Tahoe из-за карантина) — правый клик может не помочь. Снимите флаг карантина одной командой в **Терминале**:
> ```bash
> xattr -dr com.apple.quarantine /Applications/Snippi.app
> ```
> После этого запустите приложение как обычно. Это безопасно — исходный код открыт на GitHub.

### 4. Разрешения macOS

Приложение запросит два разрешения — оба нужны:

| Разрешение | Зачем | Где |
|------------|-------|-----|
| **Универсальный доступ** (Accessibility) | Перехват клавиш для триггеров сниппетов | Системные настройки → Конфиденциальность и безопасность → **Универсальный доступ** |
| **Запись экрана и системного звука** | Скриншот → текст и Скриншот → перевод | Системные настройки → Конфиденциальность и безопасность → **Запись экрана и системного звука** |

После каждого тумблера macOS попросит **перезапустить приложение** — нужно согласиться.

### 5. Если иконка не появилась в menu bar

Редкая проблема на macOS Tahoe (26+). Решается одним кликом:
- Кликните правой кнопкой по иконке Snippi в Dock → меню трея → **«Сбросить menu bar»**.

## 🪟 Windows

### 1. Скачать

Два варианта со страницы Releases:
- **`Snippi-Setup-X.Y.Z.exe`** — обычный инсталлер. **Рекомендуется**: умеет авто-обновления.
- **`Snippi-X.Y.Z.exe`** — portable-версия (без установки), авто-обновлений нет.

### 2. Запуск

- **Инсталлер:** двойной клик → установка для текущего пользователя (без прав администратора) → запуск из меню «Пуск».
- **Portable:** сохраните `.exe` куда удобно (например `Documents\Snippi\`) → двойной клик.

### 3. Предупреждение SmartScreen

При первом запуске Windows может показать **«Windows protected your PC»**:
1. Жмите **More info** (Подробнее).
2. Жмите **Run anyway** (Запустить в любом случае).

Это происходит потому что `.exe` не подписан code-signing сертификатом ($300+/год).

### 4. Автозапуск

По умолчанию приложение не прописано в автозапуск. Включить можно в самом приложении: окно → «Настройки» → «Автозапуск при входе».

## ❌ Деинсталляция

### macOS
1. Удалите **Snippi** из папки **Applications** в Корзину.
2. Удалите данные:
   ```bash
   rm -rf ~/Library/Application\ Support/snippi
   rm -rf ~/Library/Logs/snippi
   ```
3. Снимите разрешения в Системных настройках (Универсальный доступ и Запись экрана).

### Windows
1. Удалите `.exe`-файл.
2. Удалите папку `%APPDATA%\snippi\`.
